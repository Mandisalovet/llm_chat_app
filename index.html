Mandisa's Basic LLM Chat App

A simple conversational AI application built with Python, Streamlit and the OpenAI API. This project explores how language models can be integrated into interactive applications.

Open Live Application ↗ View Source Code ↗

About the Project

This application provides a chat interface where users can submit questions and receive responses from an OpenAI language model. It uses Streamlit session state to maintain conversation history and supports streamed responses.

Features

Interactive chat interface, conversational history, OpenAI API integration and streamed AI responses.

Technologies

Tools and technologies used to build the application:

Python Streamlit OpenAI API Git GitHub

Running the Application

Clone the repository, install the dependencies, configure your OpenAI API key using Streamlit Secrets, and run the application using Streamlit.

The application is deployed, but AI responses are temporarily unavailable because the OpenAI API account has exhausted its credits.
